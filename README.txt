ULTIMATE FOOTBALL 3D V2
========================

نسخة مطورة للموبايل مبنية بـ HTML/CSS/JavaScript + Three.js عبر CDN.

أهم إضافات V2:
- 10 فرق: 6 منتخبات + الأهلي + الزمالك + سموحة + بتروجيت.
- كل لاعب سجل مستقل باسمه ومركزه.
- اسم اللاعب ظاهر في شاشة التشكيلة وفوق مجسمه ثلاثي الأبعاد داخل الملعب.
- شريط تحمل مستقل لكل لاعب فوقه.
- شحن قوة التسديدة مع شريط Power ظاهر أثناء الضغط/السحب.
- جمهور متحرك بشكل خفيف حول الملعب.
- حكم 3D يتحرك قرب الكرة.
- مخالفات مبسطة تؤدي إلى ركلة حرة أو جزاء، مع بطاقات صفراء/حمراء.
- حائط دفاعي مبسط عند الركلات الحرة والجزاءات.
- عرضية بالمسح لأعلى على زر البينية.
- جودة Medium افتراضيًا وHigh اختياريًا.
- دعم لوحة المفاتيح كبديل للموبايل.

المصادر الحديثة للأسماء:
- الأهلي: الموقع الرسمي للنادي الأهلي.
- الزمالك: القائمة الرسمية المنشورة للنادي لموسم 2026-2027.
- بعض قوائم الأندية المصرية الأخرى قد تتغير أثناء الموسم؛ بيانات اللعبة مصممة بحيث يمكن تعديلها بسهولة من أعلى script.js.

ملاحظة الحجم:
المشروع متعمد أن يكون خفيفًا؛ لا توجد ملفات حشو للوصول إلى 700-800MB. الحجم الكبير المفيد يتطلب موديلات 3D حقيقية، أنيميشن، خامات، أصوات وملاعب.

التشغيل:
1) افتح index.html في متصفح يدعم ES Modules وWebGL 2.
2) يلزم اتصال بالإنترنت لتحميل Three.js من CDN في هذه النسخة.
3) إذا أردت نسخة Offline بالكامل، يمكن وضع مكتبة Three.js محليًا داخل الحزمة في إصدار لاحق.

اختبار الجودة:
- فحص صياغة JavaScript باستخدام Node --check.
- فحص وجود العناصر الرئيسية في HTML.
- فحص روابط CSS/JS.
- فحص تكرار أسماء اللاعبين داخل كل فريق قبل التسليم.
