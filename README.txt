# Supreme Arena Clash

مشروع لعبة HTML/CSS/JavaScript أصلية مستوحاة من فكرة مبارزات الـStickman والفيزياء السريعة، وليست نسخة من الأصول أو الشخصيات أو واجهة أي لعبة تجارية بعينها.

## الملفات
- index.html
- style.css
- script.js

## التشغيل
افتح index.html في متصفح حديث على الهاتف أو الكمبيوتر.

## التحكم
الهاتف: أزرار الحركة والقفز والهجوم داخل اللعبة.
الكمبيوتر: A/D أو الأسهم للحركة، W/↑/Space للقفز، F أو Enter للهجوم.

## المزايا الموجودة
- فيزياء 2D.
- خصم يتحكم به الذكاء الاصطناعي.
- 3 أوضاع: مبارزة، بقاء، فوضى.
- 7 أسلحة مختلفة.
- اختيار لون الشخصية.
- منصات متعددة.
- مؤثرات جسيمات وضربات.
- واجهة RTL ومتجاوبة مع الهاتف.
- لا تحتاج مكتبات خارجية أو إنترنت.
- اسم المبرمج: معاذ محمد عبد النبي

ملاحظة: حجم ملفات المصدر لا يحتاج أن يصل إلى 300MB كي تكون اللعبة كبيرة. حشو المشروع ببيانات فارغة للوصول إلى 300MB سيزيد الحجم فقط بدون إضافة جودة أو محتوى. يمكن لاحقًا إضافة حزم رسومات وصوت ومراحل حقيقية لزيادة حجم المحتوى بشكل مفيد.
